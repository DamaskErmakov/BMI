🛡️ BMI: EDAD Edition
Edited by Damask Ermakov | Assisted by DeepSeek

Это кастомная, исправленная и готовая к использованию сборка Bethesda Mod Installer (BMI).

В оригинальной версии BMI был ряд критических проблем, особенно при работе на новых версиях Python. В этой сборке они полностью устранены.

✨ Что было исправлено?
·Сохранение порядка модов: Устранен баг, из-за которого приоритет модов сбрасывался при перезапуске программы. Теперь ваш Load Order надежно сохраняется.

·Встроенный перевод страниц: В панель навигации встроенного браузера добавлена кнопка «Перевести» которая переводит весь текст на странице на русский. Скрипт умен: он автоматически отключается в момент скачивания, чтобы не нарушить парсинг зависимостей и Requirements.

·Работа WebView2 на Python 3.14: Добавлены необходимые DLL-библиотеки и обновлен код для корректной работы встроенного браузера на актуальных версиях Python.

📥 Как установить?
1. Перейдите в раздел Releases справа на этой странице.

2. Скачайте последнюю версию архива (BMI_EDAD.7z).

3. Распакуйте архив в любую удобную папку (например, на диск D:).

4. Запустите BMI.exe.

⚠️ Важно: Не удаляйте и не перемещайте папку _internal. Она содержит все необходимые библиотеки для работы программы.
