<h1 align="center">🛡️ BMI: EDAD Edition</h1>

<p align="center">

Это кастомная, исправленная и готовая к использованию сборка Bethesda Mod Installer (BMI). 

В оригинальной версии BMI был ряд критических проблем, особенно при работе на новых версиях Python. В этой сборке они полностью устранены.

---

## ✨ Что было исправлено?

### 🐛 Сохранение порядка модов (Load Order)
**Проблема:** При перезапуске BMI данные о приоритетах модов сбрасывались. Функция автоимпорта (`import_external_mods`) при сканировании папки заново перезаписывала объекты модов, затирая их сохраненный `priority` нулями. Кроме того, в графическом интерфейсе (PySide6) при перетаскивании модов не всегда срабатывал нужный сигнал, из-за чего изменения не попадали в файл профиля (`1.json`).
**Решение:** Исправлена логика `manager.py` — теперь перед обновлением списка создается «бэкап» текущих приоритетов, который восстанавливается после импорта. В `mods_panel.py` добавлены недостающие сигналы `rowsInserted` и `rowsRemoved` для корректной обработки Drag-and-Drop. Теперь при каждом перемещении мода его новый приоритет мгновенно фиксируется в памяти и автоматически сохраняется в активный профиль.

### 🌐 Встроенный переводчик страниц (Translation Tool)
**Проблема:** Описания и требования модов на Nexus Mods доступны только на английском. Использование внешних переводчиков в браузере неудобно, а встроенные расширения часто ломают верстку.
**Решение:** В панель навигации добавлена кнопка-переключатель «Перевести / Оригинал». При активации в WebView2 внедряется JavaScript-скрипт, который собирает текстовые узлы DOM-дерева и переводит их через API Google Translate, не затрагивая HTML-структуру страницы.

### 🛡️ Защита зависимостей
В `main_window.py` реализован предохранитель. Перед тем как BMI запускает парсинг страницы (поиск кнопок скачивания и блока Requirements), программа принудительно отключает перевод, возвращает оригинальный английский текст и ждет 0.5 секунды. Только после этого запускается анализатор, что исключает ошибки при поиске английских тегов.

### 🔧 Ручное скачивание при кастомных путях
**Проблема:** Движок WebView2 не распознавал прямые слеши (`/`), которые Python автоматически использует при генерации путей (например, `D:/Program File/BMI`).
**Решение:** Теперь путь к файлу перед сохранением проходит через функцию `os.path.normpath()`, которая автоматически конвертирует его в корректный формат Windows (`\`). Это гарантирует стабильную запись файлов в любую директорию без ошибок.

### 🔩 Фикс WebView2 для Python 3.14 (DLL & Runtime)
**Проблема:** Оригинальная версия BMI не могла инициализировать встроенный браузер (Microsoft Edge WebView2) на новых версиях Python. Ошибка `BadImageFormatException` возникала из-за того, что библиотека `pythonnet` по умолчанию пыталась загрузить старые .NET-сборки (для Framework), несовместимые с новым рантаймом Python 3.14.
**Решение:** Из официального NuGet-пакета Microsoft были извлечены актуальные управляемые сборки (`netcoreapp3.0`) и нативный загрузчик `WebView2Loader.dll` (x64). Они размещены в папке `nexus_mod_installer/_webview2`. В файле `wv2.py` перед инициализацией CLR добавлена принудительная загрузка правильного рантайма: `pythonnet.load('coreclr')`. Это заставило программу использовать современный .NET Core, что полностью решило проблему совместимости.

## 📥 Как установить?

1. Перейдите в раздел **[Releases](../../releases)** справа на этой странице.
2. Скачайте последнюю версию архива (`BMI_EDAD.7z`).
3. Распакуйте архив в любую удобную папку (например, на диск `D:`).
4. Запустите `BMI.exe`.

> ⚠️ **Важно:** Не удаляйте и не перемещайте папку `_internal`. Она содержит все необходимые библиотеки для работы программы.
